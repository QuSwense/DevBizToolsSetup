# ServiceHub Enterprise Coding Standards

## Architecture
- Features are in: Features/ServiceHubEnterprise.*/
- Each feature follows: Pages/, Components/, Services/, Models/
- Code-behind pattern required for all Blazor components

## Blazor Development
- **ALWAYS** use code-behind files (.razor.cs) NOT @code blocks
- Pattern: Page.razor + Page.razor.cs + Page.razor.css
- Code-behind class: public partial class PageName : ComponentBase

## CSS Standards
- Define CSS variables in: wwwroot/css/variables.css
- Use: property: var(--variable-name);
- Use Bootstrap 5 classes when available
- Custom styles only when Bootstrap doesn't cover the need

## C# Standards
- PascalCase for public properties and methods
- _camelCase for private fields
- Async methods: GetDataAsync() suffix
- XML comments: /// <summary> for public APIs
- Use [Required] attribute for mandatory fields
