# 07. AD Viewer

## Purpose

The AD Viewer feature provides directory and identity visibility for the enterprise environment, helping users inspect directory entities and related system structure.

## Primary routes

- `/adviewer`

## Core business outcomes

- Provide directory-view access to enterprise data.
- Improve visibility into system users, groups, or objects.
- Support operational and administrative review workflows.
