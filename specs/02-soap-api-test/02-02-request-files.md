# 02-02. Request Files

## Scope

This sub-feature covers the storage, review, and execution metadata for SOAP request files.

## Responsibilities

- Manage request file records per application.
- Store request content and metadata for execution.
- Support test-case association and extraction validation.

## Business expectations

Request files should be actionable artifacts that can be executed, inspected, compared, and associated with test-case validation flows.
