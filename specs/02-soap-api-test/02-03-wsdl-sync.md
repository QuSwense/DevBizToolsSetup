# 02-03. WSDL Sync

## Scope

This sub-feature covers WSDL import, version tracking, content records, and synchronization history.

## Responsibilities

- Import or sync WSDL content.
- Capture WSDL version and metadata records.
- Track sync events and content associations over time.

## Business expectations

WSDL data should be visible, traceable, and linked to the SOAP app inventory so the team can compare contract versions confidently.
