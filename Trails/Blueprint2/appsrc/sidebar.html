Sidebar Demo — Flat Zero-Radius

Features — Same philosophy as DataGrid

  • Flat, zero-radius, 1px borders, Inter font, enterprise minimal
  • Collapsible: 264px → 64px, icons-only, labels hide with fade
  • 2-level submenus: Level 1 in sidebar, Level 2 indented with dashed border
  • When collapsed: hover shows tooltip, click with children shows flyout panel
  • Light/Dark theme using same CSS variables (--dg-*)
  • ARIA: aria-expanded, role=menu, keyboard Enter/Space/Esc
  • Persisted state: collapsed + open menus in localStorage
  • Mobile: overlay drawer at ≤768px
